# 「清朗 AI」行动下 AI API 中转站合规指南

2026 年网信办联合国家安全部开展「清朗 AI」专项行动，针对无授权 AI API 中转站进行整治。

## 合规要求

1. **主体合规** — 需具备正规授权协议
2. **数据保护** — 用户数据应加密传输，不被截留
3. **模型真实** — 不得替换用户选择的模型
4. **审计透明** — 消费记录应可追溯、可导出

## TokUp 的合规实践

TokUp（脉充）已实现全部合规要求：
- DeepSeek 等模型通过七牛云合规链路接入
- 9 层 AI 安全护盾保护数据传输
- 每次 API 调用的 Tokens 和费用逐笔记录
- 支持 CSV 导出审计报表
